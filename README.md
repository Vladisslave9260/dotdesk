# Dotdesk (десктопная версия, Windows)

## Запуск
1. Установите Node.js (LTS) с nodejs.org.
2. В папке проекта выполните:
   npm install
   npm start
3. Чтобы собрать установщик: npm run dist

## Перед первым запуском
Параметры → Персонализация → Панель задач → «Автоматически скрывать панель задач».
Наша панель показывается поверх неё у нижнего края экрана.

## Управление
- Ctrl+Alt+W: показать или скрыть виджеты
- Ctrl+Alt+Q: выйти
- Кнопка «Выйти из приложения» в настройках справа вверху

## Как это работает
- Два прозрачных окна: виджеты (обычный уровень) и панель (всегда сверху). Мышь проходит сквозь пустые места.
- Музыка: медиасессия Windows через media.ps1 (нужен Windows PowerShell 5.1, он есть в системе). Яндекс Музыка должна быть видна в системном блоке громкости/мультимедиа.
- Спектр: захват системного звука Electron (loopback). Если захват не удался, визуализаторы работают в режиме имитации.
- Приложения на панели: ярлыки из закреплённых на панели задач (папка User Pinned\TaskBar). Запущенные определяются по окнам процессов раз в 4 секунды.
- Кнопка «Пуск» и поиск отправляют Ctrl+Esc.

## Известные ограничения первой версии
- Окно виджетов не «приклеено» к обоям: оно обычное, поэтому его скрывают горячей клавишей.
- Панель не резервирует место на экране: максимизированные окна могут уходить под неё.
- Нет значков в трее, обложки трека и кнопки «развернуть/свернуть окно» по клику на иконке.
- Эквалайзер пока влияет только на визуализацию, не на звук.
- Магазинные (UWP) приложения могут показаться без значка.

## Сборка .exe без Node.js (через GitHub)
1. Создайте бесплатный аккаунт на github.com и новый репозиторий (New repository).
2. Загрузите в него всё содержимое папки проекта (Add file → Upload files), включая скрытую папку .github.
   Если .github не загрузилась: Add file → Create new file, имя .github/workflows/build.yml, и вставьте содержимое файла build.yml из архива.
3. Откройте вкладку Actions → Build exe → дождитесь зелёной галочки (3-5 минут).
4. Откройте завершённую сборку, внизу в Artifacts скачайте dotdesk-exe: внутри один Dotdesk-0.1.0.exe, он запускается без установки.
